# One Line, One Minute: The Funniest AI Excuse

One line, 200 characters max: the funniest excuse an AI gives its human for a missed deadline. Run the builder:

```sh
python main.py
```

It verifies `entry.txt` against the gate and copies it to
`$MAKEFUN_OUTPUT_DIR/entry.txt`, printing a JSON receipt.
